把 DSH 带进桌面端

桌面端会先检查本机已有的 dsh CLI。确认后，DSH Chat 会在独立的桌面 WebView 中打开；你的 DSH Home、凭据和插件仍由 DSH 自己管理。

⚙选择 CLI、DSH Home 与端口自动检测不到时，可手动指定启动参数。

如果自动检测不到，请选择已经安装的 dsh、dsh.cmd 或绝对路径；桌面端不会自动下载 CLI。

只把这个目录作为 DSH_HOME 传给子进程，不复制、迁移或生成第二份配置。

0 表示由操作系统自动选择 loopback 空闲端口。

还没有找到 dsh？

可以先在终端安装官方 CLI，安装完成后回到这里点击「重新检测 CLI」。下面只展示命令，不会由桌面端直接执行。

  1. 确认 Node.js 可用：node --version
  2. 安装 DSH CLI：npm install --global @deepseek-ai/dsh
  3. 验证安装：dsh --version
可选：安装桌面管理桥接插件让 DSH Chat 能控制桌面端；不安装也可以继续使用 DSH Chat。

安装后，DSH Chat 的「设置 → 插件 → 桌面管理」会提供状态、启动、停止、重启和打开桌面配置按钮。
