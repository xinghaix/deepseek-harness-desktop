桌面行为

跟随系统语言，或选择固定语言。保存在 desktop-prefs.json。

开启后：仅当有任务在跑时，关窗或 ⌘Q / Ctrl+Q 会二次确认；空闲时直接退出。关掉后始终直接退出。

总开关。关闭后不创建托盘图标；下方两项不可用。

需先开启系统托盘。托盘菜单中显示的最近会话条数。0 隐藏列表，最多 20 条。

需先开启系统托盘。开启后：点 Chat 窗口 X 会隐藏到托盘，不退出。⌘Q / Ctrl+Q 和「退出」仍会退出。

快捷键

点击按键可录制新快捷键；清除可取消加速键（菜单仍可点选）；全部恢复默认还原内置绑定。与上方「开启系统托盘」「关闭窗口到托盘」配合：绑定的关闭/隐藏 Chat 快捷键始终隐藏 Chat（开托盘则进托盘，否则回程序坞/任务栏）；窗口 X 仅在开启「关闭窗口到托盘」时进托盘；退出快捷键退出应用。

  • 打开桌面设置
    ⌘, / Ctrl+,
  • 关闭/隐藏 Chat
    ⌘W / Ctrl+W
  • 退出
    ⌘Q / Ctrl+Q
  • 隐藏应用
    ⌘H
  • 隐藏其他
    ⌥⌘H
