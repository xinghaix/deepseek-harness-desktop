把 DSH 带进桌面端

桌面端会先检查本机已有的 dsh CLI。确认后，DSH Chat 会在独立的桌面 WebView 中打开；你的 DSH Home、凭据和插件仍由 DSH 自己管理。

⚙DSH 运行配置与桌面配置运行配置传给 dsh web；桌面配置只给桌面端。改完不必重启桌面应用。

运行配置

这些会传给唯一的 dsh web 子进程。配置以模态盖在 Chat 上，不会把 Chat 藏起来。关掉本页即回到 Chat；若改了工作目录、Home 或 CLI，点「重新打开 Chat」才会重启 dsh web。不必重启桌面应用。

如果自动检测不到，请选择已经安装的 dsh、dsh.cmd 或绝对路径；桌面端不会自动下载 CLI。

只把这个目录作为 DSH_HOME 传给子进程，不复制、迁移或生成第二份配置。

这是启动 DSH Chat 时的当前目录，默认沿用系统用户目录；可改为项目目录。监听端口由 dsh web 自行分配，桌面端从它的输出解析。

桌面配置

只作用于桌面端，不会改 DSH 自己的 settings.yaml。更新检查在运行控制台里设置。

固定为 DSH_HOME/.deepseek-harness-desktop，仅供桌面端使用；不会把它当作 Chat workspace。

跟随系统语言，或选择固定语言。保存在 desktop-prefs.json。

窗口关闭按钮和退出快捷键会先弹出确认。关掉此项后，无论有没有任务都会直接退出。

还没有找到 dsh？

可以先在终端安装官方 CLI，安装完成后回到这里点击「重新检测 CLI」。下面只展示命令，不会由桌面端直接执行。

  1. 确认 Node.js 可用： node --version
  2. 安装 DSH CLI： npm install --global @deepseek-ai/dsh
  3. 验证安装： dsh --version
可选：安装桌面管理桥接插件让 DSH Chat 能控制桌面端；不安装也可以继续使用 DSH Chat。

安装后，DSH Chat 的「设置 → 插件 → 桌面管理」会提供状态、启动、停止、重启和打开桌面配置按钮。
